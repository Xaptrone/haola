# fxgen

Virtual KOL marketplace for Malaysian SMEs. Dark canvas, purple accent, AI as the operating layer.

## Preview

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Bottom-left **Demo** switches surfaces.
